## 二、详细流程说明

### 第一步：初始化预授权申请

**接口**：`/api/initPreAuth`

**功能**：从外部系统获取待处理的理赔申请列表，初始化到本地数据库

**流程**：
```
┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│  1. 调用外部API获取理赔申请列表                                                                                              │
│     └── 请求：POST {getGopClaimListUrl}                                                                                     │
│     └── 响应：理赔申请列表（claimsId、患者信息、医院信息等）                                                                  │
│                                                                                                                             │
│  2. 遍历每个理赔申请                                                                                                        │
│     └── 检查是否已存在（防止重复处理）                                                                                        │
│     └── 插入 claim_case 表（初始状态：preauth_status=0）                                                                     │
│                                                                                                                             │
│  3. 返回处理结果                                                                                                            │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

**数据表**：`claim_case`（理赔申请主表）

---

### 第二步：处理基本信息

**接口**：`/api/processBasicInfo`

**功能**：获取理赔基本信息和查询数据

**流程**：
```
┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│  1. 查询 basic_info_analyzed = 0 的理赔申请                                                                                  │
│                                                                                                                             │
│  2. 调用外部API获取理赔详情                                                                                                  │
│     └── 请求：POST {getClaimInfoApiUrl}                                                                                     │
│     └── 获取：患者信息、诊断信息、预估费用等                                                                                  │
│                                                                                                                             │
│  3. 获取昂贵医院信息                                                                                                        │
│     └── 请求：POST {getExpensiveHospInfoApi}                                                                                │
│                                                                                                                             │
│  4. 获取直付医院信息                                                                                                        │
│     └── 请求：POST {getDirectPayHospApi}                                                                                    │
│                                                                                                                             │
│  5. 存储分析结果                                                                                                            │
│     └── 插入 basic_info_analysis 表                                                                                         │
│     └── 更新 claim_case.basic_info_analyzed = 1                                                                             │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

**数据表**：`basic_info_analysis`（基本信息分析表）

---

### 第三步：处理保单条款

**接口**：`/api/processPoliciesInfo`

**功能**：下载并分析保单条款PDF文档

**流程**：
```
─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│  1. 查询 policies_analyzed = 0 的理赔申请                                                                                    │
│                                                                                                                             │
│  2. 调用外部API获取保单条款URL列表                                                                                           │
│     └── 请求：POST {getPolicyWordingUrlApi}                                                                                 │
│     └── 获取：TOB保单、产品保单URL列表                                                                                        │
│                                                                                                                             │
│  3. 过滤有效文件（PDF/DOCX/XLSX）                                                                                            │
│                                                                                                                             │
│  4. 下载文件到本地                                                                                                          │
│     └── OSS URL替换为公网地址                                                                                                │
│                                                                                                                             │
│  5. 调用LLM分析PDF内容                                                                                                      │
│     └── 模型：qwen-long-latest                                                                                              │
│     └── 分析：保险责任、除外责任、免赔额、赔付比例等                                                                          │
│                                                                                                                             │
│  6. 存储分析结果                                                                                                            │
│     └── 插入 policies_analysis 表（区分tob/product类型）                                                                     │
│     └── 更新 claim_case.policies_analyzed = 1                                                                               │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

**数据表**：`policies_analysis`（保单条款分析表）

**使用模型**：`qwen-long-latest`（长文档处理模型）

---

### 第四步：处理理赔资料

**接口**：`/api/processDocumentsInfo`

**功能**：下载并分析理赔资料图片

**流程**：
```
─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│  1. 查询 documents_analyzed = 0 的理赔申请                                                                                   │
│                                                                                                                             │
│  2. 调用外部API获取理赔文档列表                                                                                              │
│     └── 请求：POST {getDocumentsUrlApi}                                                                                     │
│     └── 获取：医疗票据、检查报告、病历等文档URL                                                                               │
│                                                                                                                             │
│  3. 过滤有效文件（PNG/JPG/JPEG/PDF等）                                                                                       │
│                                                                                                                             │
│  4. 检查是否已存在分析数据（避免重复处理）                                                                                    │
│                                                                                                                             │
│  5. 下载图片到本地                                                                                                          │
│                                                                                                                             │
│  6. 图片预处理                                                                                                              │
│     └── 转换为base64格式                                                                                                    │
│     └── 图片质量评估                                                                                                        │
│                                                                                                                             │
│  7. 调用LLM分析图片内容（双重验证）                                                                                          │
│     └── 主分析：qwen-vl-plus                                                                                                │
│     └── 交叉验证：qvq-plus-latest                                                                                           │
│     └── 分析：医疗费用、诊断信息、治疗项目等                                                                                  │
│                                                                                                                             │
│  8. 比较两次OCR结果一致性                                                                                                    │
│     └── 调用 compare_ocr_results()                                                                                          │
│                                                                                                                             │
│  9. 存储分析结果                                                                                                            │
│     └── 插入 document_analysis 表                                                                                           │
│     └── 更新 claim_case.documents_analyzed = 1                                                                              │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
```

**数据表**：`document_analysis`（理赔资料分析表）

**使用模型**：
- `qwen-vl-plus`：主要文档分析
- `qvq-plus-latest`：备用/交叉验证分析

---

### 第五步：生成预授权审核结果

**接口**：`/api/genPreAuthResult`（单线程）或 `/api/genPreAuthResultMultiThread`（多线程）

**功能**：综合所有分析结果，生成最终预授权决策

**流程**：
```
┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│  1. 查询已完成三项分析的理赔申请                                                                                             │
│     └── basic_info_analyzed = 1                                                                                             │
│     └── documents_analyzed = 1                                                                                              │
│     └── policies_analyzed = 1                                                                                               │
│                                                                                                                             │
│  2. 获取各项分析结果                                                                                                        │
│     └── 基础信息分析结果                                                                                                    │
│     └── 理赔资料分析结果（调用 cut_document_info() 精简整理）                                                                │
│     └── 保单条款分析结果（TOB + Product）                                                                                    │
│                                                                                                                             │
│  3. 业务规则分析                                                                                                            │
│     └── 住院指针分析：get_inpatient_info()（仅住院类型）                                                                     │
│     └── APV信息分析：get_apv_info()                                                                                         │
│     └── 除外项目分析：get_except_info()                                                                                     │
│     └── 医院信息获取：HospitalInfo                                                                                          │
│     └── 价格知识库：call_dashscope_application()                                                                             │
│                                                                                                                             │
│  4. 预分析优化（可选）                                                                                                      │
│     └── 第一步预判：pre_analyze_preauth_result1()（基于APV信息）                                                             │
│        └── 返回"12"则直接采用结果                                                                                            │
│     └── 第二步预判：pre_analyze_preauth_result2()（基于综合信息）                                                            │
│        └── 返回"13"则直接采用结果                                                                                            │
│                                                                                                                             │
│  5. 生成最终决策                                                                                                            │
│     └── 模型：qwen3.6-plus                                                                                                  │
│     └── 调用：analyze_preauth_result()                                                                                      │
│     └── 输出格式：{"result": "01 - 审核通过", "reason": "原因说明"}                                                          │
│                                                                                                                             │
│  6. 更新外部系统                                                                                                            │
│     └── 请求：POST {updatePreAuthResultUrl}                                                                                 │
│     └── 数据：claimsId、preAuthResult、preAuthReason                                                                        │
│                                                                                                                             │
│  7. 更新本地数据库                                                                                                          │
│     └── 更新 claim_case.preauth_status = 1                                                                                  │
│     └── 更新 claim_case.preauth_result                                                                                      │
│     └── 更新 claim_case.ai_result（结果代码）                                                                                │
│     └── 更新 claim_case.ai_result_desc（结果描述）                                                                           │
─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

**使用模型**：`qwen3.6-plus`（文本生成模型）

## 三、审核结果代码说明

| 结果代码 | 结果描述 | 说明 |
|---------|---------|------|
| 01 | 审核通过 | 符合保险责任，予以预授权 |
| 02 | 审核不通过-非保险责任 | 不在保险责任范围内 |
| 03 | 审核不通过-等待期 | 处于等待期内 |
| 04 | 审核不通过-既往症 | 属于既往症免责范围 |
| 05 | 审核不通过-除外责任 | 属于除外责任范围 |
| 06 | 审核不通过-免赔额 | 未达到免赔额标准 |
| 07 | 部分通过 | 部分项目符合保险责任 |
| 08 | 需人工审核 | 情况复杂，需人工介入 |
| 09 | 资料不全 | 缺少必要理赔材料 |
| 10 | 医院不符 | 非指定/直付医院 |
| 11 | 额度不足 | 保险额度已用尽 |
| 12 | 快速通过-APV预审 | 基于APV信息快速通过 |
| 13 | 快速通过-综合预审 | 基于综合信息快速通过 |

## 五、定时任务调用顺序

建议按以下顺序定时调用API：

| 步骤 | 接口 | 说明 | 依赖 |
|-----|------|------|------|
| 1 | `/api/initPreAuth` | 获取新理赔申请 | 无 |
| 2 | `/api/processBasicInfo` | 处理基本信息 | 步骤1完成 |
| 3 | `/api/processPoliciesInfo` | 处理保单条款 | 步骤1完成 |
| 4 | `/api/processDocumentsInfo` | 处理理赔资料 | 步骤1完成 |
| 5 | `/api/genPreAuthResultMultiThread` | 生成审核结果 | 步骤2、3、4均完成 |

## 七、系统特点

1. **智能化**：基于阿里云通义千问大模型，自动分析医疗文档和保单条款
2. **双重验证**：使用两个视觉模型交叉验证，提高OCR准确率
3. **预分析优化**：通过两步预判机制，快速处理简单案件，提升效率
4. **可配置**：业务规则通过数据库表管理，支持动态调整
5. **多线程支持**：支持多线程批量处理，提高吞吐量
6. **完整日志**：详细的日志记录，便于问题追踪和审计
